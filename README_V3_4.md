# Saudi Sensing CRM V3.4

## Commercial Fields

The Quotation Workspace includes:

- Total Price Before VAT
- Cost Price
- Discount
- VAT %
- Net Before VAT
- VAT Amount
- Total Including VAT
- Gross Margin %
- Gross Margin Value
- Revision

Gross margin is calculated automatically:

Gross Margin Value = Net Selling Price - Cost Price

Gross Margin % = Gross Margin Value / Net Selling Price × 100

## Documents

The proposal owner can upload:

- Technical Proposal
- Commercial Proposal
- Cost Sheet
- Vendor Quotation
- Customer RFQ
- Supporting Documents
- Other files

Files are stored under:

`documents/<Quotation ID>/`

## Inbox

A new Inbox section shows action items assigned to the logged-in owner.

The proposal engineer can send a completed quotation back to the concern owner as:

`READY FOR SUBMISSION`

## Approval Process

1. Proposal Engineer prepares quotation and uploads documents.
2. Send for Approval.
3. Proposal Manager approves.
4. GM gives final approval.
5. Concern owner receives it in Inbox as Approved for Submission.

## Notifications

- Notification icon and unread count appear at the top.
- Notifications section lists all notifications.
- Dashboard includes Inbox and Notification counts.
