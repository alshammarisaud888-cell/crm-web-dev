# Saudi Sensing CRM V3.0

## Assignment at Opportunity to Quotation

The Send Opportunity to Quotation dialog now requires:

- Assigned Owner
- Target Submission Date
- Assignment Notes

The owner dropdown displays all active owners without exclusion.

## Quotation Workflow

- ASSIGNED
- IN PROGRESS
- INTERNAL REVIEW
- SUBMITTED
- CUSTOMER REVIEW
- REVISED
- WON
- LOST
- CANCELLED

The CRM tracks:

- Assigned date
- Work started date
- Submitted date
- Completed date
- Assignment notes
- Current age in days
- Overdue quotation requests

## Dashboard

The dashboard now includes:

- Assigned Quotations
- Overdue Quotations

## Owners

All active owners are available for quotation assignment, regardless of their role.
