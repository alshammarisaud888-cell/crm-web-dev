# Saudi Sensing CRM V3.5

## Fixed Left Sidebar

- Dashboard
- Accounts
- Customer Contact
- Leads
- Opportunities
- Quotations
- Pipeline Analytics
- Reports

## Fixed Top Navigation

- Inbox with open-item counter
- Notifications with unread counter
- Owners

## Removed from the Visible Interface

- Meetings
- Activities
- Data Migration
- Migrated Pipeline Details

The underlying tables and historical records remain stored safely in the database.

Data Migration is hidden because the initial migration has already been completed and it is not part of normal daily CRM work.

Migrated Pipeline Details is hidden because it duplicates information already available in Opportunities, Pipeline Analytics and Reports.
