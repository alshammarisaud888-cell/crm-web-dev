# Saudi Sensing CRM V3.6

## Lead Creation

- Account is required when creating a Lead.
- Account is selected from the existing Accounts list.
- Company Name is filled automatically from the selected Account.
- Owner is assigned automatically from the logged-in creator.
- Owner is read-only and cannot be changed manually.
- Next Action Date uses a calendar picker.
- The Leads table displays the linked Account.

If there are no Accounts, the CRM asks the user to create an Account first.
