# Saudi Sensing CRM V2.3

## Executive Dashboard Filters

The dashboard now supports:

- Year
- Month
- Account
- Sales Owner
- CRM Stage
- Business Unit
- Status
- Clear Filters

All dashboard KPIs and executive PDF reporting use the selected filters.

## Section-Level Export

Every operational section now includes:

- Export PDF
- Export Excel

Sections covered:

- Executive Dashboard
- Accounts
- Contacts
- Leads
- Opportunities
- Migrated Pipeline Details
- Quotations
- PoCs
- Meetings
- Activities
- Pipeline Analytics

Dashboard and Pipeline exports show the active filters in the exported file.

## Start

1. Extract into a new folder.
2. Run `run_app.bat`.
3. Login with admin / admin123.
