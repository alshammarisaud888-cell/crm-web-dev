# Saudi Sensing CRM V3.2

## Quotation Workspace

The workspace now opens using either:

- A single click on the blue Quotation ID
- The green Open button

Double-clicking is no longer required.

## PDF Logo

The report logo now:

- Preserves its original aspect ratio
- Is centered
- Is not stretched
- Uses a proportional size of 58.0 mm by 81.9 mm

## Start

Extract the ZIP into a new folder and run `run_app.bat`.
