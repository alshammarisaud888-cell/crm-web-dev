# Saudi Sensing CRM V3.3

## Reliable Quotation Workspace

The quotation workspace is now a full CRM page instead of a modal dialog.

Open it using:

- The blue Quotation ID
- The green Open button

The full-page workspace contains:

- Linked opportunity details
- Account and opportunity value
- Assigned owner
- Workflow status
- Calendar target date
- Workflow timestamps
- Prepared quotation value
- Discount
- VAT
- Revision
- Live totals
- Assignment and commercial notes
- Save and Back buttons

If any error occurs, the CRM displays it and creates:

`quotation_workspace_error.log`
