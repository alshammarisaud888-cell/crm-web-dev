# Saudi Sensing CRM V3.8

## New Lead

- Account starts blank.
- No account number or account name appears until the user selects an Account.
- Company Name fills only after Account selection.
- Job Title, Email and Mobile are arranged inside the dialog and will wrap safely.

## Print Buttons

### Opportunity Workspace
A Print button generates a professional PDF containing:
- CRM opportunity data
- Original Excel information
- Commercial values
- Forecast and ownership data
- Quality flags

### Quotation Workspace
A Print button generates a quotation summary PDF containing:
- Linked opportunity and account
- Assigned owner and workflow status
- Selling price, cost, VAT and total
- Gross margin percentage and value
- Revision and notes

Existing section-level PDF and Excel export buttons remain available.
