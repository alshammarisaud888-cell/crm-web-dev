# Saudi Sensing CRM V3.1

## Calendar Date Selection

The following date fields now use a calendar picker:

- Target Submission Date when sending an Opportunity to Quotation
- Quotation Date when creating a new Quotation
- Valid Until when creating a new Quotation
- Target Submission Date inside the Quotation Workspace

Users no longer need to type these dates manually.

## Quotation Workspace

Double-click the blue Quotation ID in the Quotations table.

A dedicated dynamic workspace opens with:

- Linked Opportunity ID
- Account
- Opportunity name and type
- Opportunity stage, probability and value
- Sales Owner and Technical Owner
- Assigned quotation owner
- Workflow status
- Target submission date
- Assignment notes
- Assigned, work-started, submitted and completed timestamps
- Prepared quotation value
- Discount
- VAT rate
- Revision
- Live Net Before VAT calculation
- Live VAT Amount calculation
- Live Total Including VAT calculation
- Commercial and proposal notes

The proposal engineer can prepare the quotation offline, then enter the final value and update the workflow inside this workspace.

An Open icon is also available for users who prefer a single click.
